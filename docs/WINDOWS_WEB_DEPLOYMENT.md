# 替抗蓟化 Windows 本地 Web 版部署与启动方案

## 1. 为什么正式比赛使用这一版

这一版仍然是 Web 页面，但不是公网网站。页面、接口、数据库、语音识别和女声合成都在比赛 Windows 电脑本机运行，浏览器只负责显示、麦克风采集和声音播放。

相较 Electron 桌面包，正式方案减少了一层桌面壳和代码签名风险：

- 不安装软件，不写注册表，不要求管理员权限；
- 使用 Windows 已安装的 Edge 或 Chrome；
- 内置官方 Windows x64 Node.js 便携运行时，电脑无需安装 Node.js；
- 自动选择空闲本地端口，不再固定依赖 4173；
- 只监听 `127.0.0.1`，局域网其他电脑无法访问；
- SenseVoice、ZipVoice Emilia 女声和全部模型均随包携带；
- 断网后页面、数据、语音输入和语音输出仍可运行；
- Electron 安装版与免安装版只作为第二级备用。

## 2. 交付文件

正式交付为：

```text
替抗蓟化-Windows本地Web版-1.0.0-x64.zip
```

必须先完整解压，不能直接在压缩包预览窗口中运行。解压后的主要入口：

- `启动系统.bat`：正式启动；
- `打开系统页面.bat`：服务已启动但浏览器页面被关闭时重新打开；
- `停止系统.bat`：安全关闭服务并落盘数据；
- `诊断启动.bat`：出现问题时显示详细错误；
- `runtime/server.log`：运行日志；
- `runtime/startup-error.txt`：最近一次启动错误；
- `runtime/data/tihua.db`：本地业务数据库。

## 3. Windows 电脑要求

- Windows 10/11 x64；
- Microsoft Edge 或 Google Chrome；
- 推荐近五年 Intel Core i5 / AMD Ryzen 5 或更高；
- 推荐 16GB 内存、3GB 以上可用磁盘；
- 显示分辨率优先 1920×1080，系统缩放 100%；
- 无需独立显卡、无需 Node.js、无需 Python、无需互联网。

## 4. 首次部署

1. 将 ZIP 完整复制到 Windows 电脑本地磁盘；
2. 右键 ZIP，选择“全部解压”；
3. 建议解压到 `D:\DJTK\` 或桌面，不要放在网盘同步目录；
4. 双击 `启动系统.bat`；
5. Edge/Chrome 会以独立应用窗口打开；
6. 浏览器询问麦克风权限时选择“允许”；
7. 点击“语音”，说“这批鸡安全吗？”；
8. 确认识别文字、女性声音和数字人口型均正常；
9. 双击 `停止系统.bat`，确认可以正常停止；
10. 断开 Wi-Fi、网线、手机热点和 VPN，再完整重复一次。

## 5. 正式比赛启动

1. 接好麦克风、大屏和音响；
2. Windows 显示缩放设为 100%；
3. 关闭 Wi-Fi、网线、热点、VPN 和会议软件；
4. 双击 `启动系统.bat`；
5. 页面打开后做一次语音问答；
6. 全屏展示可按浏览器的 `F11`；
7. 比赛结束后双击 `停止系统.bat`，不要直接关机。

重复双击“启动系统”不会重复创建数据库或占用多个端口：若服务已经运行，只会重新打开现有页面。

## 6. 数据备份

数据跟随解压目录保存：

```text
runtime\data\tihua.db
```

备份前先双击 `停止系统.bat`。随后复制整个 `runtime\data\`，包括可能存在的 `tihua.db-wal` 和 `tihua.db-shm`。不要在服务运行时只复制主数据库文件。

建议准备：

- 一台正式 Windows 主机；
- 一台已完成断网验收的备用 Windows 主机；
- 两个分别保存完整 ZIP 和数据库备份的 U 盘。

## 7. 常见问题

### 页面没有自动打开

双击 `打开系统页面.bat`。如果提示系统未启动，双击 `诊断启动.bat` 查看原因。

### 麦克风不能使用

进入“Windows 设置 → 隐私和安全性 → 麦克风”，开启麦克风访问以及桌面应用访问。再检查 Edge/Chrome 地址栏左侧的麦克风权限。

### 有文字但没有女声

检查 Windows 输出设备和音量，关闭占用声卡的会议软件。查看 `runtime/server.log` 是否有语音模型错误。

### 语音第一次较慢

第一次问答会加载本地模型。比赛开始前先完成一次语音问答，使模型进入热状态。不要同时打开多个系统页面连续播报。

### 批处理文件被安全软件阻止

本方案运行的是官方 Node.js Windows x64 便携二进制和本地脚本，不安装系统服务。比赛前由电脑管理员把整个解压目录加入允许列表，并在主机、备用机上各运行一次。

## 8. 正式验收底线

- 彻底断网后能启动；
- 标准视图与经典可视化均能切换；
- 100% 缩放下无遮挡；
- 连续语音问答 10 次不崩溃；
- 声音为本地女性声音，不是浏览器系统音色；
- 关闭页面后可以重新打开，数据不丢失；
- 安全停止后重新启动，原数据仍在；
- 主机与备用机均完成同样测试。
