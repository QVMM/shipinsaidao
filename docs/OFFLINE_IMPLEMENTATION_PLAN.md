# DJTK 比赛离线版实施计划

## 目标

在不依赖互联网、云端模型或浏览器云语音服务的条件下，交付可在 Windows 10/11 64 位 x64/ARM64 比赛电脑上独立运行的完整应用：本地证据问答、离线中文语音输入、离线中文女声输出、自然数字人状态与嘴型表现、启动自检、桌面/本地一键启动，以及可复制到备用电脑的安装版和免安装版。

## 明确不做

- 不在比赛现场调用 MiMo、Render 或其他云端服务。
- 不把通用本地大模型作为业务判定来源；结论继续由平台证据与确定性规则产生。
- 不把 CUDA 或独立显卡作为现场运行条件；高质量视频数字人仅作为后续增强，正式链路使用 CPU 可运行的轻量动态嘴型。
- 不覆盖现有线上项目；本项目使用独立目录和独立分支。

## 关键组件

- `server/offline-voice.js`：加载 sherpa-onnx、SenseVoice、ZipVoice Emilia 自然女声和 Matcha Baker 备用女声，提供本地 ASR/TTS。
- `server/app.js`：增加离线语音状态、转写与合成接口，比赛模式禁止外部语音请求。
- `src/lib/offline-audio.js`：浏览器内采集麦克风 PCM、重采样、静音自动收尾。
- `src/lib/djtk-human.js`：接入本地语音输入输出和数字人状态机。
- `public/avatar/`：待机、倾听、思考、播报素材与后续预生成视频入口。
- `scripts/install-offline-models.mjs`：下载、校验并安装全部离线模型。
- `desktop/`：Electron 桌面壳与全屏启动逻辑。
- `docs/DEPLOYMENT_OFFLINE.md`、`docs/STARTUP_OFFLINE.md`：详细部署、启动、备份和现场应急方案。

## 有序工作单元

1. 建立离线语音模块及模型安装器；用单元测试验证模型状态、PCM/WAV 编码和接口契约。
2. 增加离线语音 API；验证在禁用网络与清空 MiMo 配置后仍可回答、转写和生成女声音频。
3. 接入前端麦克风采集、自动停录和本地转写；保留文字按钮作为现场兜底。
4. 将数字人升级为待机、倾听、思考、播报状态机，口型使用闭合、轻启、张开三级音量驱动。
5. 增加 Electron 桌面壳、一键启动、自检页和比赛全屏模式。
6. 生成 Windows x64 标准安装版与免安装版，校验 PE 架构、语音运行库和模型资源。
7. 完成真实 ASR/TTS 冒烟测试，以及 Windows 部署、启动、备份和断网验收说明。

## 验证标准

- 单元测试覆盖：离线状态、语音接口、女声音色、无云请求、音频编码、意图回答。
- 功能测试覆盖：麦克风输入流程、文字回答、离线 TTS、数字人状态切换、两种大屏模式。
- 关闭 Wi-Fi 后启动并完成至少一次本地问答与女声播报。
- 模型文件缺失时给出明确自检结果，并保留文字与快捷问题能力。
- `npm run build`、桌面打包检查及原有视觉回归通过。

## 发布与回滚

- 线上版本保持不变；离线版从本目录单独构建和交付。
- 比赛包包含主机包、备用机包和模型校验清单。
- 若动态语音或视频模块异常，自动退回预生成女声/视频；若麦克风异常，快捷问题按钮仍可完成全部核心讲解。
