# 替抗蓟化离线竞赛版：启动方案

## A. 正式比赛启动（推荐）

1. 提前关闭 Wi-Fi、手机热点和 VPN。
2. 接入外接麦克风和大屏，系统声音输出选择现场音响。
3. 双击“替抗蓟化离线竞赛版”应用。
4. 首次出现麦克风权限提示时选择“允许”。
5. 页面打开后点击“语音”，说“这批鸡安全吗？”。
6. 确认页面出现识别文字，并由女声播报回答。
7. 按 `F11` 进入或退出全屏；全屏状态下按 `Esc` 也可退出。

桌面版自动选择空闲本地端口，不会再因 4173 被占用而无法访问。

## B. 源码双击启动

- macOS：双击 `bin/start-offline-mac.command`
- Windows：双击 `bin/start-offline-windows.bat`

脚本会先检查本地模型，再启动桌面窗口。此方式需要项目内已经存在 `node_modules`、`dist` 与 `models/offline`。

## C. 浏览器应急启动

如果 Electron 窗口无法打开，可在项目根目录运行：

```bash
npm run build
npm run offline
```

然后用 Chrome 打开：

```text
http://127.0.0.1:4173/?offline=1#/stage
```

经典可视化：

```text
http://127.0.0.1:4173/?offline=1&view=classic#/stage
```

如果 4173 被占用：

```bash
PORT=4180 npm run offline
```

再打开 `http://127.0.0.1:4180/?offline=1#/stage`。

## D. 每次比赛前的 5 分钟检查

在项目根目录执行：

```bash
npm run offline:check
npm run offline:smoke
```

再人工检查：

- 新版指挥舱无横向滚动、底部卡片无遮挡；
- 经典可视化可切换回来；
- 麦克风按钮可点击，停顿后自动结束录音；
- “这批鸡安全吗”“氟苯尼考筛查结果”“下一步点哪里”均能回答；
- 声音是本地自然女声，不是系统浏览器声音；
- 播报时嘴型强弱随声音变化，停止后回到自然待机；
- 关闭网络后刷新页面仍能正常工作；
- 显示器缩放设为 100%，浏览器缩放设为 100%。

## E. 现场故障处理

### 页面打不开

优先重启桌面应用。源码模式则检查终端是否显示本地地址；若端口冲突，按上文更换端口。

### 语音按钮不可用

在系统隐私设置中允许应用/Chrome 使用麦克风，拔插麦克风后重启应用。来不及处理时直接使用快捷问题或文字输入，核心研判不受影响。

### 有文字但没有声音

确认系统没有静音、输出设备为现场音响，然后运行 `npm run offline:check`。若自然女声模型异常，可临时设置 `OFFLINE_VOICE_ENGINE=matcha` 后启动，系统仍会使用完全离线的 Baker 女声。

### 声音卡顿

关闭其他占用 CPU 的应用，不要同时开多个本系统窗口。把 `OFFLINE_TTS_THREADS` 保持在 4；不建议比赛现场临时调高。

### 数据异常

立刻关闭应用，把赛前备份数据库覆盖回原位置后重启。覆盖前先保留当前异常数据库，便于赛后排查。

## F. 现场兜底优先级

1. Electron 正式桌面版；
2. portable / zip 备用桌面版；
3. 源码浏览器版；
4. 快捷问题 + 文字回答；
5. 预先录制的全流程视频。

语音和数字人是增强层，业务数据、判定和页面始终是第一优先级。
