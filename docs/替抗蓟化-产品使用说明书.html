2 产品是干什么的

第一次打开，先记住三个问题。后面都围着它们转。

2.1 这批鸡能不能上桌？

打开后先看「这批鸡」。大字会告诉你：可以上桌，或 还不能出证。

下面三条约定：

  • 喂了没有加大蓟
  • 有没有用饲用抗生素
  • 兽药有没有检出来

演示批次「蓟化-2026-0812」默认是：喂了大蓟粗提物，没用饲用抗生素，氟苯尼考未检出。结论是可以上桌。

2.2 从养殖到检测能不能查到？

工作人员登录后，顺着左边菜单走：

这批鸡 → 养殖过程 → 现场快检 → 健康评价 → 检测报告 → 追溯码 → 买家看到的

上面还有一条更短的故事线：

这批鸡 → 怎么养的 → 检没检出药 → 出证明 → 买家扫到什么

每一页开头都有三行：「这一页看什么 / 和你有什么关系 / 下一步做什么」。下面有一个金色主按钮，带着你往下走。

系统做三件事：把结果记下来，生成一页 A4 报告，生成追溯码并打开买家页。

2.3 它不替你做什么？

说清楚边界，避免现场问到做不到的事。

  • 仪器在现场做。软件不驱动仪器，不连设备，不自动出化验数字。
  • 界面里不能新建批次，不能删批次，不能管用户、不能改别人的密码。
  • 买家页不用登录。工作人员页必须登录。
  • 本系统只服务「替抗蓟化」这一条产品线。药材只写大蓟、大蓟粗提物。

3 使用前五件事

动手之前，先做这五件。做完再打开浏览器。

第一件：分清你是工作人员还是买家。

工作人员要登录，改自己负责的那一段。买家只扫码，不登录。

第二件：准备对的账号。

演示密码全是 Demo#2026。正式上线必须改。评委演示请用 suyuan 或 guanli，否则点不出报告。

第三件：记住这一批。

演示批次是 蓟化-2026-0812。鸡在河南省郑州市荥阳市康店镇，双汇·郑州农发共建养殖基地，8000 羽。日粮加了大蓟粗提物。

第四件：手机要扫码，就用公网地址出码。

二维码按当前网页地址生成。你在本机 127.0.0.1 出的码，手机扫不开。要扫，先打开公网临时地址，再出码。见第 4 章。

第五件：改完不用点「保存」。

登录后改表格，大约 400 毫秒会自动写入本机数据库。刷新还在。没有权限的栏位会顶上弹出一句话，并退回原来的数。

4 怎么打开

4.1 工作人员（本机）

浏览器打开：

http://127.0.0.1:4173/

没登录会落到登录页。登录后落到「这批鸡」。

服务没起来时，先看附录 A。

4.2 工作人员（临时公网）

现场投大屏、或让手机扫码，可用当前临时隧道：

https://notices-blah-violation-principles.trycloudflare.com/

注意：隧道挂了会换新地址。换了以后，旧码扫不开。请用新地址重新登录、重新出码。

4.3 买家（不用登录）

买家打开：

{当前网站地址}/#/trace/蓟化-2026-0812

两个现成例子：

场景地址
本机预览http://127.0.0.1:4173/#/trace/蓟化-2026-0812
手机扫码（当前隧道）https://notices-blah-violation-principles.trycloudflare.com/#/trace/蓟化-2026-0812

本机地址只给同一台电脑看。手机请用公网那一行。

工作人员登录后，左边点「买家看到的」，也能看到同一页的手机样子。那是预览。真正给买家的是上面的公开地址。

4.4 二维码跟哪个地址走

追溯码按 当前网页的地址 + #/trace/批次号 生成。

  • 你在 http://127.0.0.1:4173/ 点「生成追溯码」，码里就是本机地址。
  • 你在 https://notices-blah-violation-principles.trycloudflare.com/ 登录后再出码，手机才能扫开。

投大屏演示：先打开公网地址，再出码，再让评委扫。

5.1 怎么登录

  1. 打开第 4 章里的工作人员地址。
  2. 看到卡片：左边是标志，标题「替抗蓟化」，副题「减抗鸡肉 · 能不能追溯」。
  3. 填写用户名、密码。
  4. 点金色按钮「进入」。

登录成功，会进入「这批鸡」。

登录页有一句提示：买家扫码不用登录。演示账号在说明书里，默认密码必须改。

5.2 怎么退出

左侧栏最下面，能看见你的显示名、用户名和岗位。点「退出」。退出后回到登录页。

换岗位不要只点「现场怎么分工」。那只会跳到对应页面，账号还是原来的。请先退出，再用另一个账号登录。

6 屏幕各块

登录之后，屏幕分成左边一条、上面一条、中间一大块。

6.1 左边（侧栏）

从上到下：

  1. 标志和名称：替抗蓟化 · 减抗鸡肉 · 能不能追溯。
  2. 七个菜单：这批鸡 / 养殖过程 / 现场快检 / 健康评价 / 检测报告 / 追溯码 / 买家看到的。当前页会高亮。
  3. 你是谁：显示名、用户名、岗位。这里有「退出」。
  4. 现场怎么分工（折叠起来的）：点开能看到四个岗位说明。点某一个，只是跳到那一页，不是换账号。
  5. 一句说明：现场真做检测。这里只录入、出报告、出追溯码。改动能写进服务器。
  6. 恢复演示数据：只有 suyuan 和 guanli 看得到这个按钮。别人登录时没有。

6.2 上面（顶栏和故事线）

  • 左边写着：替抗蓟化 · 你在看：当前页标题。
  • 右边有一颗批次胶囊，默认是 蓟化-2026-0812。
  • 再下面是五步故事线：这批鸡 → 怎么养的 → 检没检出药 → 出证明 → 买家扫到什么。当前步会标出来。

「检没检出药」包含现场快检和健康评价两页。「出证明」包含检测报告和追溯码两页。

6.3 中间（每一页的固定三件套）

不管进哪一页，先看这三件：

  1. 三行说明：这一页看什么；和你有什么关系；下一步做什么。
  2. 一个金色主按钮：带你到下一页，或当场生成报告 / 生成码。
  3. 本页内容：结论、表格、报告或手机样子。

有的页还有次要操作，例如「两分钟演示：直接出报告」「打印 / 另存 PDF」「重出」。它们不是主路径，可按需点。

6.4 顶上的黄条提示

保存失败、没权限、恢复成功，都会在故事线下面出一条提示。看那一行就够。常见原文见第 11 章。

顶部偶尔有一条很细的进度条。那是在和服务器说话。不用等它消失再点，也不用刷新。

7 第一次怎么走

三种走法。评委在场用前两种。四人分岗演示用第三种。

7.1 完整路径（推荐，大约五到八分钟）

请用 suyuan 或 guanli 登录。用别的账号，走到「出报告」会被拦住。

  1. 登录，停在「这批鸡」。读大字结论和三条事实。
  2. 点「下一步：看这批鸡怎么养的」。
  3. 看日粮是不是大蓟粗提物，用药本是不是写着饲用抗生素未使用。
  4. 点「下一步：看现场有没有检出兽药」。
  5. 看定性是不是阴性、结果是不是未检出。
  6. 点「下一步：看实验室复核和鸡健不健康」。
  7. 看实验室数字，看深色条是不是比浅色条短。
  8. 点「下一步：生成检测报告」。若还没出过报告，会先生成，再打开 A4 证明。
  9. 点「下一步：出追溯码」。还没出过码就生成。没有报告时，出码会顺手把报告补上。
  10. 点「下一步：看买家扫开是什么」。或退出后打开公开地址。

故事就是：这批鸡 → 怎么养的 → 检没检出药 → 出证明 → 买家扫到什么。

7.2 两分钟路径（赶时间）

同样需要 suyuan 或 guanli。

  1. 登录，停在「这批鸡」。
  2. 不要顺着走。点次要按钮 「两分钟演示：直接出报告」。
  3. 系统按当前批次生成 A4 报告，并跳到「检测报告」。
  4. 再点「下一步：出追溯码」。
  5. 再点「下一步：看买家扫开是什么」。

演示批次已经预填了养殖、快检、评价。两分钟路径不再一页页打开，直接出证明。

若你用的是 yangzhi，点这个按钮会顶上提示：当前账号（智慧养殖）不能生成检测报告。请退出，换 suyuan 或 guanli。

7.3 四人分岗路径（展示现场怎么分工）

四个人各登各的号。不要共用一个管理员号假装分工。

顺序谁登进哪一页做什么交给谁
1yangzhi养殖过程核日粮、用药本。可改数字。改完等大约半秒告诉快检：这批可以抽检
2kuaijian现场快检仪器做完后，把阴性和未检出记进去告诉评价：筛查过了
3pingjia健康评价把实验室定量和炎症数字记进去告诉溯源：可以出证
4suyuan检测报告 → 追溯码生成报告，出码，打开买家页评委扫码

管理员 guanli 一个人也能走完全程。四人演示时建议不用它，以免看不出岗位边界。

每一岗改完，下一个人刷新或重新进入即可。数据在服务器里，不是只存在你这一台浏览器。

8 每一页怎么用

下面按左边七个菜单写。每节先说人话，再列你能点的东西。

8.1 这批鸡

这一页看什么：这批减抗鸡肉能不能吃、从哪来、检没检出药。

打开先看大字：

  • 可以上桌：喂了大蓟、没用饲用抗生素、药也没检出来。
  • 还不能出证：上面三条里有没过关的。下面会用人话写原因。

三条事实各占一块：

你看到意思
是 · 喂了大蓟日粮添加物里写了「蓟」
还不是 · 日粮里还没写大蓟添加物被改没了，或写成了不含「蓟」的字
是 · 没喂饲用抗生素用药本里抗生素那一行是未使用，或根本没有抗生素行
还不是 · 饲用抗生素未清零用药本里还有抗生素，且结果不是未使用
是 · 氟苯尼考未检出快检阴性或实验室未检出
还不是 · 氟苯尼考需复核筛查或定量没过关

页脚有一行小字：批次号 · 基地名 · 羽数 · 出栏日。演示默认是蓟化-2026-0812 · 双汇·郑州农发共建养殖基地 · 8000 羽 · 2026-08-12 出栏。

主按钮：下一步：看这批鸡怎么养的。

次要按钮：两分钟演示：直接出报告（只要溯源员或管理员）。

这一页没有表格可改。它是总览。

8.2 养殖过程

这一页看什么：这批鸡喂了什么，有没有用饲用抗生素。

开头一段人话。演示默认是：这批鸡吃的是加了大蓟的日粮（大蓟粗提物 800 mg/kg 饲料）。用药本上写着：饲用抗生素未使用。疫苗按规程做，那不是饲用抗生素。

三个卡片：

批次与基地：批次号、鸡群编号、养殖基地、共建单位、地址、鸡舍、品种、入孵、进苗、计划出栏、本群羽数、密度。

8.3 现场快检

这一页看什么：出栏前抽检，这批肉有没有筛出常见兽药。

标题旁边有一颗状态：没检出 / 阳性 / 无效。

开头人话会带上分钟数。演示默认大约 45 分钟筛完：没检出兽药。

软件不启动仪器。仪器在现场做完，你只把结果填进来。

两个卡片：

样品与方法：样品编号、采样时间、取样部位、方法、前处理分钟、出结果分钟、查的哪种药、操作人。

演示预填：样品 QC-0812-03，胸肌 / 肝脏混样，查氟苯尼考，前处理 40 分钟，出结果 5 分钟。操作人是 2 号 快速检测工程师。

筛查结果：

栏位怎么填
定性三选一：阴性 / 阳性 / 无效
结果表述演示是「未检出」
质控线质控线显色是否正常
检出限说明演示写着与 50 μg/kg 对齐
备注可空

定性选「阳性」或「无效」，首页会变成还不能出证。选「无效」时，人话是：试纸不能用，先重做。

只有 kuaijian 和 guanli 能改这一页。

8.4 健康评价

这一页看什么：实验室把药再测一遍，再看鸡的炎症高不高。

开头人话。演示默认：实验室也没测出药。炎症比常规养法低，肉更好。

实验室定量：检测日期、仪器、标准曲线 R、检出限、结果表述、定量值（未检出则留空）、操作人。演示仪器写 HPLC，结果表述「未检出（<50）」，操作人是 3 号 分析测试工程师。

炎症对照：四条横条。浅色是常规喂了抗生素的鸡，深色是这批。深色更短 = 炎症更低 = 肉更好。下面可以改本批次和对照的数字。

四个名字是 IL-1β、IL-6、TNF-α、CRP。演示里深色都明显短于浅色。若你把本批次数字改高，过了「比对照低三成」这条线，结论会变成还不能出证，原因是炎症还偏高。

肠道菌群：可选。Shannon、乳酸菌变化、大肠杆菌变化。不是出证的硬门槛，会出现在报告里。

9 改数据之后

改表格不用找保存按钮。没有这个按钮。

  1. 你改完一栏，离开这一栏，或改完下拉框。
  2. 系统在大约 400 毫秒后，把改动写进本机数据库。
  3. 有权限：顶上进度条闪一下，数字留下。刷新还在。别人换账号进来也能看见。
  4. 没权限：数字退回，顶上出现第 11 章里的那句人话。

报告和码不会因为你改数字而自动重出。你改完养殖、快检或评价，若已经出过报告，请到「检测报告」点「按当前数据重出」。需要新码就到「追溯码」点「重出」。

首页「可以上桌 / 还不能出证」会跟着当前数字即时变。你不必重出报告，也能先看到结论变了。

建议演示时：先让评委看默认的「可以上桌」，再把快检改成阳性，让大字变成「还不能出证」，再恢复演示数据。一次就能看懂系统不是死页面。

12 注意事项

  1. 口令。 五个演示账号共用 Demo#2026。这是演示口令。正式上线必须改。不要把这个口令用到真实养殖场。
  2. 药材和批次用字。 只写大蓟、大蓟粗提物。批次只写蓟化-2026-0812。讲解、报告、投影都不要写成别的药材名。
  3. 仪器和软件分开。 快检和实验室的仪器是现场真设备。软件只记录、出证明、出码。不要对评委说「软件在跑仪器」。
  4. 出码地址。 二维码跟当前网站地址走。本机出的码，手机扫不开。公网隧道挂了会换域名，旧码作废，要重出。
  1. 一个演示批次。 界面不能新建批次，不能切换一堆批次。恢复演示数据只会回到蓟化-2026-0812。
  2. 没有用户管理界面。 不能在网页里加号、删号、改别人的岗。五个账号是灌演示数据时写好的。
  3. 打印用浏览器。 检测报告页点「打印 / 另存 PDF」，纸张选 A4。不要对这一页用系统截图去充当正式件。
  4. 改完会落库。 刷新、换电脑、换账号，都能看见上次有权限的人写下的数。演示结束请恢复演示数据，避免下一场接着看你改乱的数。
  5. 会话。 点「退出」再把电脑给下一位。不要只关标签。
  6. 本说明书不覆盖未做功能。 若有人问「在哪新建第二批鸡」「在哪给新同事开账号」，答案是：这个版本没有这两块界面。
