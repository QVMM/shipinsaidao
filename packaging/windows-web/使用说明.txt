替抗蓟化 Windows 本地 Web 版

第一次使用：
1. 右键压缩包，选择“全部解压”。不能在压缩包窗口里直接运行。
2. 进入解压后的文件夹，双击排在最上方的“00-首次使用-安装并启动.bat”。
3. 程序会自动识别 Intel/AMD x64 或 Windows ARM64，检查文件、创建“打开替抗蓟化网页”桌面图标，并且只有在本地 Web 服务真正就绪后才用普通 Edge 或 Chrome 窗口打开。
4. 第一次使用语音时，点击“允许”访问麦克风。

以后每次使用：
1. 双击桌面上的“打开替抗蓟化网页”。
2. 页面如果被关闭，再双击一次同一个图标即可重新打开，不会重复启动。
3. 比赛结束后，双击桌面上的“关闭替抗蓟化系统”，再关闭电脑。

如果移动了整个系统文件夹，再双击一次“00-首次使用-安装并启动.bat”，即可更新桌面图标。
若无法启动，双击“diagnose-startup.bat”，并把 runtime\server.log 发给技术人员。

本系统只在本机 127.0.0.1 运行；页面、数据和语音识别可断网使用。语音输出联网时优先使用 MiMo，断网、超时或未配置 MiMo 时自动使用 Edge/Chrome 调用的电脑自带声音。
支持 Windows 10/11 64 位（Intel/AMD x64 与 Qualcomm/Windows ARM64）；推荐 16GB 内存、1920×1080 分辨率、显示缩放 100%。
