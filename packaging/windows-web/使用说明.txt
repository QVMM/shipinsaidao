替抗蓟化 Windows 本地 Web 版

正式使用：
1. 必须先完整解压本压缩包，不能在压缩包窗口里直接运行。
2. 双击“启动系统.bat”。
3. 等待 Edge 或 Chrome 自动打开。
4. 第一次使用语音时，允许浏览器访问麦克风。
5. 页面关闭后，可双击“打开系统页面.bat”重新打开。
6. 比赛结束后双击“停止系统.bat”，再关闭电脑。
7. 若无法启动，双击“诊断启动.bat”，并查看 runtime\server.log。

本系统只在本机 127.0.0.1 运行；页面、数据、语音识别和女性语音输出均可断网使用。
推荐 Windows 10/11 x64、16GB 内存、1920×1080 分辨率、显示缩放 100%。
