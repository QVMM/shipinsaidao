# 替抗蓟化离线竞赛版：启动方案

## A. 正式比赛启动（推荐）

1. 在 Windows 中关闭 Wi-Fi、拔掉网线，并关闭手机热点和 VPN。
2. 接入外接麦克风和大屏，系统声音输出选择现场音响。
3. 双击桌面上的“替抗蓟化离线竞赛版”；没有安装权限时直接双击免安装版 `.exe`。
4. 首次出现麦克风权限提示时选择“允许”。
5. 页面打开后点击“语音”，说“这批鸡安全吗？”。
6. 确认页面出现识别文字，并由女声播报回答。
7. 按 `F11` 进入或退出全屏；全屏状态下按 `Esc` 也可退出。

桌面版自动选择空闲本地端口，不会再因 4173 被占用而无法访问。

## B. Windows 系统设置

- 设置 → 系统 → 显示：缩放设为 `100%`，分辨率优先 `1920×1080`；
- 设置 → 隐私和安全性 → 麦克风：开启“麦克风访问”和“允许桌面应用访问麦克风”；
- 设置 → 系统 → 声音：比赛麦克风设为输入设备、现场音响设为输出设备；
- 设置 → 系统 → 电源和电池：比赛期间选择“最佳性能”，关闭自动睡眠；
- 关闭会抢占麦克风的会议软件、语音助手和浏览器标签页。

## C. 源码双击启动（仅维护兜底）

- Windows：双击 `bin/start-offline-windows.bat`

脚本会先检查本地模型，再启动桌面窗口。此方式需要项目内已经存在 `node_modules`、`dist` 与 `models/offline`。

## D. 浏览器应急启动

如果 Electron 窗口无法打开，可在项目根目录运行：

```bash
npm run build
npm run offline
```

然后用 Chrome 打开：

```text
http://127.0.0.1:4173/?offline=1#/stage
```

经典可视化：

```text
http://127.0.0.1:4173/?offline=1&view=classic#/stage
```

如果 4173 被占用：

```bash
PORT=4180 npm run offline
```

再打开 `http://127.0.0.1:4180/?offline=1#/stage`。

## E. 每次比赛前的 5 分钟检查

在项目根目录执行：

```bash
npm run offline:check
npm run offline:smoke
```

再人工检查：

- 新版指挥舱无横向滚动、底部卡片无遮挡；
- 经典可视化可切换回来；
- 麦克风按钮可点击，停顿后自动结束录音；
- “这批鸡安全吗”“氟苯尼考筛查结果”“下一步点哪里”均能回答；
- 联网时优先使用 MiMo，断网时自动使用电脑自带中文声音；
- 播报时嘴型强弱随声音变化，停止后回到自然待机；
- 关闭网络后刷新页面仍能正常工作；
- 显示器缩放设为 100%，浏览器缩放设为 100%。

## F. 现场故障处理

### 页面打不开

优先重启桌面应用。源码模式则检查终端是否显示本地地址；若端口冲突，按上文更换端口。

### 语音按钮不可用

在系统隐私设置中允许应用/Chrome 使用麦克风，拔插麦克风后重启应用。来不及处理时直接使用快捷问题或文字输入，核心研判不受影响。

### 有文字但没有声音

确认系统没有静音、输出设备为现场音响，并检查浏览器标签页没有静音。MiMo 不可用时不需要调整模型，系统会自动使用电脑自带中文声音。

### 声音卡顿

关闭其他占用声音设备的应用，不要同时开多个本系统窗口连续播报。

### 数据异常

立刻关闭应用，把赛前备份数据库覆盖回原位置后重启。覆盖前先保留当前异常数据库，便于赛后排查。

## G. 现场兜底优先级

1. Electron 正式桌面版；
2. Windows 免安装版；
3. 源码浏览器版；
4. 快捷问题 + 文字回答；
5. 预先录制的全流程视频。

语音和数字人是增强层，业务数据、判定和页面始终是第一优先级。
